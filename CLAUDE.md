# Camber

## Commit messages

Write the subject line in the imperative mood — phrase it as an instruction to the
codebase, completing the sentence "If applied, this commit will ___".

- Good: `Add the transom edge to the mesh boundary`, `Fix sheet trims stopping short`
- Bad: `Added the transom edge...`, `Adds the transom edge...`, `Adding the transom edge...`

This applies to the subject line. The body, if there is one, is ordinary prose.
